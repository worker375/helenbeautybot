# Beauty Salon Telegram Bot

Полноценный Telegram-бот для салона красоты с системой онлайн-записи клиентов, админ-панелью, управлением мастерами, услугами и свободными окнами.

## Функционал клиента

### Онлайн-запись

* выбор услуги;
* выбор мастера;
* отображение индивидуальной цены и длительности услуги у конкретного мастера;
* выбор свободного окна;
* ввод имени и телефона;
* подтверждение записи.

### Личный кабинет

* просмотр своих записей;
* возврат в главное меню на любом этапе сценария.

### Валидация данных

* проверка корректности номера телефона;
* формат даты: `день.месяц.год`;
* формат времени: `ЧЧ:ММ`.

---

# Админ-панель

## Управление услугами

* добавление новых услуг;
* редактирование названия услуг;
* удаление услуг;
* назначение мастеров на услуги;
* создание нового мастера прямо из раздела услуг.

## Управление мастерами

* добавление мастеров;
* переименование мастеров;
* удаление мастеров.

## Индивидуальные цены и длительность

Для каждого мастера можно отдельно настраивать:

* стоимость услуги;
* длительность процедуры.

Пример:

* Женская стрижка — Анна: 2500 ₽ / 60 мин
* Женская стрижка — Мария: 1800 ₽ / 90 мин

## Управление свободными окнами

* добавление свободных окон;
* просмотр всех свободных окон списком;
* автоматическое скрытие занятых окон.

# Установка

## 1. Клонирование проекта

```bash
git clone https://github.com/worker375/helenbeautybot.git
```

## 2. Создание виртуального окружения

Windows:

```bash
python -m venv .venv
.venv\Scripts\activate
```

Linux / MacOS:

```bash
python3 -m venv .venv
source .venv/bin/activate
```
