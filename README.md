# Beauty Salon Telegram Bot v6

MVP Telegram-бота для записи клиентов в салон красоты.

## Главное в версии v6

Сохранена логика v5 и возвращен явный раздел редактирования цены и длительности для каждого мастера отдельно.

Путь в админке:

**⚙️ Админ-панель → 💰 Услуги: цены и длительность → выбрать услугу → выбрать мастера → редактировать цену / длительность**

Например:

- Женская стрижка — Анна: 2500 ₽, 60 мин
- Женская стрижка — Мария: 1800 ₽, 90 мин

У клиента при первом выборе услуги цены не показываются, потому что они зависят от выбранного мастера. Цена и длительность появляются после выбора мастера.

## Возможности

- запись клиентов на услуги;
- выбор услуги, мастера, даты и времени;
- русские дни недели;
- формат даты `дд.мм.гггг`;
- проверка телефона в формате `+79991234567`;
- главное меню доступно из сценариев;
- админ-панель без команды `/admin` через кнопку;
- показ свободных окон списком;
- добавление/редактирование/удаление мастеров;
- добавление/редактирование/удаление услуг;
- назначение мастеров на услугу;
- создание мастера прямо при назначении услуги;
- отдельная цена и длительность услуги для каждого мастера.

## Запуск

1. Создать виртуальное окружение:

```bash
python -m venv .venv
```

2. Активировать:

Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

Windows CMD:

```cmd
.venv\Scripts\activate.bat
```

macOS/Linux:

```bash
source .venv/bin/activate
```

3. Установить зависимости:

```bash
pip install -r requirements.txt
```

4. Создать файл `.env` по примеру `.env.example`:

```env
BOT_TOKEN=токен_бота_от_BotFather
ADMIN_IDS=ваш_telegram_id
```

5. Запустить:

```bash
python bot.py
```

## Важно при обновлении со старой версии

Если структура базы изменилась и бот ведет себя странно на тестах, удалите файл `salon_bookings.sqlite3`, чтобы база создалась заново.
